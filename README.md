# Руководство по проверке домашнего задания (aiohttp + WebSockets)

Реализован асинхронный сервер на `aiohttp`, поддерживающий постоянную WebSocket-связь с клиентами, REST API (`POST /news`) для интеграции с внешними сервисами и безопасные холостые Ping/Pong запросы.

## 1. Запуск сервера
1. Убедитесь, что установлена библиотека `aiohttp`:
   ```bash
   pip install aiohttp
   ```
2. Запустите сервер командой:
   ```bash
   python server.py
   ```
3. Откройте в браузере страницу: `http://localhost:8080`

## 2. Шаги для проверки функционала

### Пункт А: Клиентский интерфейс и WebSockets
При переходе на `http://localhost:8080` страница автоматически подключается к серверу через веб-сокеты. Статус изменится на зеленый **«Подключено к серверу»**.

### Пункт Б: Периодическая проверка соединения (Ping/Pong)
Нажмите на странице кнопку **«Проверить соединение (Ping)»**. Браузер отправит текстовый WebSocket-фрейм, сервер вернет ответ `pong`, и на экране появится уведомление. Этот запрос ничего не меняет на сервере (идемпотентен).

### Пункт В: Прием новостей по POST и веерная рассылка
Для имитации внешнего сервиса можно отправить POST-запрос через **Talend API Tester** или `curl`:
* **Метод:** `POST`
* **URL:** `http://localhost:8080/news`
* **Заголовки (Headers):** `Content-Type: application/json`
* **Тело (Body):**
  ```json
  {
    "text": "Тестовая новость от стороннего сервиса!"
  }
  ```
**Результат:** Сервер вернет `200 OK`, а новость моментально отобразится в верхней части ленты на всех открытых вкладках браузера без обновления страниц.
